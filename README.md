## GitHub Pages deployment
The included GitHub Actions workflow deploys the Vite build to GitHub Pages. For a user-site URL, create/rename the repository to `Sushilcoder.github.io` (GitHub usernames are case-sensitive in the displayed URL) and ensure the Pages source is GitHub Actions.
